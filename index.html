About This Lab

This Virtual Fourier Series Lab provides an interactive environment for exploring Fourier series mathematics. Using this lab, you can study the theory, see the formulas, examine worked examples, and run your own simulations — computing \(a_0\), \(a_n\), and \(b_n\) coefficients for any user-defined function on an arbitrary integration interval.

All wave visualizations are computed in real time using numerical integration (midpoint rule), giving instant feedback as you experiment with different functions and number of harmonic terms.

📚 Theory of Fourier Series
Understanding the mathematical foundation of Fourier series over [0, 2π]

1. Introduction

A Fourier series is a way to represent a periodic function as a sum of simple sine and cosine waves. It was introduced by French mathematician Jean-Baptiste Joseph Fourier (1768–1830) while studying heat flow.

Any reasonably well-behaved periodic function \( f(x) \) with period \( 2\pi \) can be expressed as an infinite sum of trigonometric functions:

$$f(x) = \frac{a_0}{2} + \sum_{n=1}^{\infty}\left[a_n \cos(nx) + b_n \sin(nx)\right]$$

where \(a_0\), \(a_n\), and \(b_n\) are called the Fourier coefficients.

2. Dirichlet Conditions

For a function \(f(x)\) to have a convergent Fourier series, it must satisfy the Dirichlet conditions:

  1. The function \(f(x)\) must be bounded (finite in value).
  2. It must have a finite number of maxima and minima in each period.
  3. It must have a finite number of discontinuities in each period (and these must be finite jump discontinuities).
  4. The function must be absolutely integrable: \( \int_0^{2\pi} |f(x)|\, dx < \infty \).
Note: The Dirichlet conditions are sufficient (not necessary). If satisfied, the Fourier series converges to \(f(x)\) at all points of continuity.

3. Convergence Theorem

At a point of continuity \(x_0\), the Fourier series converges to:

$$S(x_0) = f(x_0)$$

At a point of jump discontinuity, the Fourier series converges to the average of the left and right limits:

$$S(x_0) = \frac{f(x_0^-) + f(x_0^+)}{2}$$

4. Orthogonality of Trigonometric Functions

The trigonometric functions \(\{1, \cos x, \sin x, \cos 2x, \sin 2x, \ldots\}\) form an orthogonal set over \([0, 2\pi]\). This means:

$$\int_0^{2\pi} \cos(mx)\cos(nx)\,dx = \begin{cases} 0 & m \neq n \\ \pi & m = n \neq 0 \end{cases}$$ $$\int_0^{2\pi} \sin(mx)\sin(nx)\,dx = \begin{cases} 0 & m \neq n \\ \pi & m = n \end{cases}$$ $$\int_0^{2\pi} \cos(mx)\sin(nx)\,dx = 0 \quad \text{for all } m, n$$

This orthogonality is what allows us to isolate each coefficient individually.

5. Even and Odd Functions

Even Function: \(f(-x) = f(x)\)

All sine terms vanish: \(b_n = 0\)

The series contains only cosines (cosine series)

Odd Function: \(f(-x) = -f(x)\)

All cosine terms vanish: \(a_0 = 0,\; a_n = 0\)

The series contains only sines (sine series)

6. Parseval's Theorem

Parseval's theorem relates the energy in the time domain to the energy in the frequency domain:

$$\frac{1}{\pi}\int_0^{2\pi} [f(x)]^2\,dx = \frac{a_0^2}{2} + \sum_{n=1}^{\infty}\left(a_n^2 + b_n^2\right)$$

This is particularly useful for computing the sum of certain infinite series.

7. Physical Interpretation

Fourier series have profound physical meaning. Any periodic signal — whether a musical note, an electrical waveform, or a vibrating string — can be decomposed into its constituent pure frequencies (harmonics):

  • \(a_0/2\): The DC component (average value)
  • n=1: Fundamental frequency (first harmonic)
  • n=2: Second harmonic (twice the frequency)
  • n=k: k-th harmonic

The simulator in this lab lets you see exactly how adding more harmonics builds up the approximation to any function.

📐 Fourier Series Formulas
Complete reference of all formulas for Fourier series on [0, 2π]

Main Formula

The Fourier series expansion of \(f(x)\) on \([0,\, 2\pi]\) is defined as:

$$\boxed{f(x) = \frac{a_0}{2} + \sum_{n=1}^{\infty}\left[a_n \cos(nx) + b_n \sin(nx)\right]}$$

Fourier Coefficients

Constant Term — \(a_0\)

$$a_0 = \frac{1}{\pi}\int_0^{2\pi} f(x)\,dx$$

This gives twice the mean value of \(f(x)\) over the period. The term \(a_0/2\) is the DC offset.

Cosine Coefficients — \(a_n\)

$$a_n = \frac{1}{\pi}\int_0^{2\pi} f(x)\cos(nx)\,dx, \quad n = 1, 2, 3, \ldots$$

Sine Coefficients — \(b_n\)

$$b_n = \frac{1}{\pi}\int_0^{2\pi} f(x)\sin(nx)\,dx, \quad n = 1, 2, 3, \ldots$$

General Interval \([a,\, b]\)

For a function with period \(L = b - a\) on the interval \([a, b]\):

$$f(x) = \frac{a_0}{2} + \sum_{n=1}^{\infty}\left[a_n \cos\!\left(\frac{2n\pi x}{L}\right) + b_n \sin\!\left(\frac{2n\pi x}{L}\right)\right]$$
$$a_0 = \frac{2}{L}\int_a^{b} f(x)\,dx, \quad a_n = \frac{2}{L}\int_a^{b} f(x)\cos\!\left(\frac{2n\pi x}{L}\right)dx, \quad b_n = \frac{2}{L}\int_a^{b} f(x)\sin\!\left(\frac{2n\pi x}{L}\right)dx$$

Special Function Results (on [0, 2π])

Function \(f(x)\) \(a_0\) \(a_n\) \(b_n\)
\(f(x) = 1\) \(2\) \(0\) \(0\)
\(f(x) = x\) \(2\pi\) \(0\) \(-\dfrac{2}{n}\)
\(f(x) = x^2\) \(\dfrac{8\pi^2}{3}\) \(\dfrac{4}{n^2}\) \(-\dfrac{4\pi}{n}\)
Square wave \(0\) \(0\) \(\dfrac{4}{n\pi}\) (odd \(n\)), \(0\) (even \(n\))

Parseval's Identity

$$\frac{1}{\pi}\int_0^{2\pi} [f(x)]^2\,dx = \frac{a_0^2}{2} + \sum_{n=1}^{N}\left(a_n^2 + b_n^2\right)$$

Integration by Parts (Quick Reference)

$$\int u\,dv = uv - \int v\,du$$

Useful identities when computing coefficients:

$$\int x\cos(nx)\,dx = \frac{x\sin(nx)}{n} + \frac{\cos(nx)}{n^2} + C$$ $$\int x\sin(nx)\,dx = -\frac{x\cos(nx)}{n} + \frac{\sin(nx)}{n^2} + C$$ $$\int x^2\cos(nx)\,dx = \frac{x^2\sin(nx)}{n} + \frac{2x\cos(nx)}{n^2} - \frac{2\sin(nx)}{n^3} + C$$ $$\int x^2\sin(nx)\,dx = -\frac{x^2\cos(nx)}{n} + \frac{2x\sin(nx)}{n^2} + \frac{2\cos(nx)}{n^3} + C$$

Example 1

Find the Fourier series of \(f(x) = x\) on \([0, 2\pi]\)

1

Compute \(a_0\)

$$a_0 = \frac{1}{\pi}\int_0^{2\pi} x\,dx = \frac{1}{\pi}\left[\frac{x^2}{2}\right]_0^{2\pi} = \frac{1}{\pi}\cdot\frac{4\pi^2}{2} = 2\pi$$
2

Compute \(a_n\)

$$a_n = \frac{1}{\pi}\int_0^{2\pi} x\cos(nx)\,dx = \frac{1}{\pi}\left[\frac{x\sin(nx)}{n} + \frac{\cos(nx)}{n^2}\right]_0^{2\pi}$$ $$= \frac{1}{\pi}\left[\frac{2\pi\sin(2\pi n)}{n} + \frac{\cos(2\pi n)}{n^2} - \frac{\cos(0)}{n^2}\right] = \frac{1}{\pi}\left[0 + \frac{1}{n^2} - \frac{1}{n^2}\right] = 0$$
3

Compute \(b_n\)

$$b_n = \frac{1}{\pi}\int_0^{2\pi} x\sin(nx)\,dx = \frac{1}{\pi}\left[-\frac{x\cos(nx)}{n} + \frac{\sin(nx)}{n^2}\right]_0^{2\pi}$$ $$= \frac{1}{\pi}\left[-\frac{2\pi\cos(2\pi n)}{n} + \frac{\sin(2\pi n)}{n^2} - 0\right] = \frac{1}{\pi}\left[-\frac{2\pi}{n}\right] = -\frac{2}{n}$$
4

Final Result

$$x = \pi - 2\sum_{n=1}^{\infty}\frac{\sin(nx)}{n} = \pi - 2\sin x - \sin 2x - \frac{2}{3}\sin 3x - \cdots$$
Example 2

Find the Fourier series of \(f(x) = x^2\) on \([0, 2\pi]\)

1

Compute \(a_0\)

$$a_0 = \frac{1}{\pi}\int_0^{2\pi} x^2\,dx = \frac{1}{\pi}\left[\frac{x^3}{3}\right]_0^{2\pi} = \frac{1}{\pi}\cdot\frac{8\pi^3}{3} = \frac{8\pi^2}{3}$$
2

Compute \(a_n\) (using integration by parts twice)

$$a_n = \frac{1}{\pi}\int_0^{2\pi} x^2\cos(nx)\,dx$$ $$= \frac{1}{\pi}\left[\frac{x^2\sin(nx)}{n} + \frac{2x\cos(nx)}{n^2} - \frac{2\sin(nx)}{n^3}\right]_0^{2\pi} = \frac{1}{\pi}\cdot\frac{4\pi}{n^2} = \frac{4}{n^2}$$
3

Compute \(b_n\)

$$b_n = \frac{1}{\pi}\int_0^{2\pi} x^2\sin(nx)\,dx$$ $$= \frac{1}{\pi}\left[-\frac{x^2\cos(nx)}{n} + \frac{2x\sin(nx)}{n^2} + \frac{2\cos(nx)}{n^3}\right]_0^{2\pi} = \frac{1}{\pi}\left(-\frac{4\pi^2}{n}\right) = -\frac{4\pi}{n}$$
4

Final Result

$$x^2 = \frac{4\pi^2}{3} + 4\sum_{n=1}^{\infty}\left[\frac{\cos(nx)}{n^2} - \frac{\pi\,\sin(nx)}{n}\right]$$
Example 3

Find the Fourier series of the Square Wave on \([0, 2\pi]\)

Let \(f(x) = \begin{cases} 1 & 0 < x < \pi \\ -1 & \pi < x < 2\pi \end{cases}\)

1

Compute \(a_0\)

$$a_0 = \frac{1}{\pi}\left[\int_0^{\pi} 1\,dx + \int_\pi^{2\pi}(-1)\,dx\right] = \frac{1}{\pi}[\pi - \pi] = 0$$
2

Compute \(a_n\)

$$a_n = \frac{1}{\pi}\left[\int_0^{\pi}\cos(nx)\,dx - \int_\pi^{2\pi}\cos(nx)\,dx\right] = 0$$

This equals zero because the square wave is an odd function (when shifted by π).

3

Compute \(b_n\)

$$b_n = \frac{1}{\pi}\left[\int_0^{\pi}\sin(nx)\,dx - \int_\pi^{2\pi}\sin(nx)\,dx\right]$$ $$= \frac{1}{\pi}\left[-\frac{\cos(nx)}{n}\right]_0^\pi - \frac{1}{\pi}\left[-\frac{\cos(nx)}{n}\right]_\pi^{2\pi}$$ $$= \frac{2}{\pi n}(1 - \cos(n\pi)) = \begin{cases} \dfrac{4}{n\pi} & n \text{ odd} \\ 0 & n \text{ even} \end{cases}$$
4

Final Result

$$f(x) = \frac{4}{\pi}\sum_{n=1,3,5,\ldots}\frac{\sin(nx)}{n} = \frac{4}{\pi}\left(\sin x + \frac{\sin 3x}{3} + \frac{\sin 5x}{5} + \cdots\right)$$
Example 4

Find the Fourier series of \(f(x) = \pi - x\) on \([0, 2\pi]\)

1

Compute \(a_0\)

$$a_0 = \frac{1}{\pi}\int_0^{2\pi}(\pi - x)\,dx = \frac{1}{\pi}\left[\pi x - \frac{x^2}{2}\right]_0^{2\pi} = \frac{1}{\pi}\left[2\pi^2 - 2\pi^2\right] = 0$$
2

Compute \(a_n\)

$$a_n = \frac{1}{\pi}\int_0^{2\pi}(\pi - x)\cos(nx)\,dx = \frac{1}{\pi}\left[(\pi-x)\frac{\sin(nx)}{n} + \frac{\cos(nx)}{n^2}\right]_0^{2\pi} = 0$$
3

Compute \(b_n\)

$$b_n = \frac{1}{\pi}\int_0^{2\pi}(\pi - x)\sin(nx)\,dx = \frac{1}{\pi}\left[-(\pi-x)\frac{\cos(nx)}{n} - \frac{\sin(nx)}{n^2}\right]_0^{2\pi}$$ $$= \frac{1}{\pi}\left[0 - \frac{\pi}{n}\right] \cdot (-1) \cdot (-1) = \frac{1}{\pi}\cdot\frac{\pi}{n} \cdot 2 = \frac{2}{n}$$
4

Final Result

$$\pi - x = 2\sum_{n=1}^{\infty}\frac{\sin(nx)}{n} = 2\sin x + \sin 2x + \frac{2}{3}\sin 3x + \cdots \quad x \in (0,\, 2\pi)$$

At \(x=0\) and \(x=2\pi\) (discontinuities), the series converges to 0 (the average of π and −π).
